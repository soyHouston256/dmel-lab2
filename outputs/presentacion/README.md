# Presentación UTEC

## Versión vigente

[DMEL-UTEC-lab2.pptx](DMEL-UTEC-lab2.pptx): 24 diapositivas, estilo UTEC sobrio, gráficos y tablas editables, notas y referencias. Acompañada por [guion-dmel-cierre.txt](guion-dmel-cierre.txt) y el [complemento breve para Houston](complemento-cierre-Houston.txt).

Incluye metodología, adaptación horaria, comparación original LSTM–DMEL, ablación limitada a tres épocas y test completo de ambos modelos. La [evidencia del cierre](../verification/cierre4h-local-20261008/README.md) fue descargada y auditada localmente el 8 de octubre de 2026. Test significa exportación completa sin etiquetas; no se presentan métricas de test.

Se mantiene la numeración 1–19 de la versión anterior. Diapositiva 20: ablación; 21: test completo; 22: conclusiones; 23–24: referencias. La demo de Houston sobre 16–19 permanece utilizable. El guion distribuye el objetivo de 18 minutos en metodología, implementación y resultados/cierre. El [montaje final](../video-dmel/README.md) dura 17:49.84 y ya incluye la locución de 20–22. Persistencia y múltiples semillas quedan como extensiones.
